# Changelog

## 2.0
- Folder, text, table, hex, picture, media-tag, version-info, registry and document comparison; three-way merge; synchronisation.
- Git: difftool/mergetool integration, built-in revision browser, local-changes-vs-last-commit, remote-into-checkout, summary with
  ahead/behind and merge preview, fetch, restore/stage, author filter.
- Text Compare: GitLens-style blame, file and line history, Combine (keep both sides), compare pasted text, outline and Go to symbol
  with added / removed / changed methods, 80+ languages, Java `.class` files shown as disassembled bytecode.
- Large files: near-linear diff, responsive loading, hex compare of multi-gigabyte files.
- Installer with EULA page, update-in-place, clean uninstall (optional keep-my-data), optional code signing.
- Diagnostics: error log and Help > Report a problem; opt-in update check.
- Security hardening: verified Git download, safe redirects, no cleartext passwords, git option-injection guards, archive size caps.
